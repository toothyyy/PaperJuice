# PaperJuice

每周自动从 Europe PMC / PubMed / arXiv / CrossRef / OpenAlex 检索你关心的领域文献，
按影响因子/分区筛选，本地大模型打分排序，Windows 桌面应用一键查看。

## 下载

点击仓库文件列表里的 **`PaperJuice-Setup-0.2.0.exe`**（约 37 MB）→
在文件页点击 **Download raw file** 即可下载。

## 安装

1. 双击运行安装包 → 若弹出 UAC 请求管理员权限，点「是」（程序装进 Program Files）
2. 在「附加任务」页确认：
   - **创建桌面快捷方式**（默认已勾选）
   - **启用每周自动检索**（可选，默认不勾；周一 09:00 自动跑一次）
3. 点「完成」，桌面出现 **PaperJuice** 图标，双击打开

> 安装向导为简体中文。系统要求：Windows 10/11 x64。
> 首次运行会自动初始化数据目录。
> 若提示「无法验证发布者」，说明程序未做代码签名，点「更多信息 → 仍要运行」即可。

## 首次配置（1 分钟）

1. 打开应用 → 左侧 **⚙ 配置**
2. 在「领域与关键词」里改成你自己的方向（每行一个领域，关键词逗号分隔）
3. **时间窗口（月）**：填 6 就只显示近 6 个月发表的文献
4. **EasyScholar 密钥**（可选）：填了才有影响因子/分区，**IF 阈值也才会生效**
   - 去 <https://www.easyscholar.cc> 免费注册 → 右上角用户名 →「开放接口」复制密钥
   - 密钥只需粘进配置页，**不用手工设置环境变量**
5. **LLM**（可选）：默认已预填本机 Ollama 配置（`localhost:11434`），
   只在你点「生成简介」时才调用；没装 Ollama 就留着不管
6. 点「保存配置」→ 左侧 **🔄 立即检索**

## 卸载

控制面板 →「卸载程序」→ PaperJuice。
会自动删除每周计划任务；`%LOCALAPPDATA%\PaperJuice` 里的历史文献与配置**保留**，
重装后数据仍在。要彻底清掉，手动删除该目录。

## 数据存在哪

| 内容 | 位置 |
|---|---|
| 文献数据库、配置 | `%LOCALAPPDATA%\PaperJuice\` |
| 运行日志 | `%LOCALAPPDATA%\PaperJuice\logs\paperjuice.log` |
| 程序本体（只读） | `C:\Program Files\PaperJuice\` |
